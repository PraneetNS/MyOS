# Security Policy

## Supported Versions
Security updates are actively provided for the latest code on the `main` branch.

| Version / Branch | Supported |
|:---|:---|
| `main` | :white_check_mark: |
| Releases (`v*`) | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability or bypass in MyOS (e.g., agent sandbox escape, kernel capability circumvention, or audit log tampering), please report it responsibly:

- **Email**: Send detailed reproduction steps and logs to `praneet.dev@example.com` (or project maintainer).
- **GitHub Security Advisory**: Open a private draft security advisory via GitHub's Security tab.

Please allow up to 48 hours for acknowledgment before any public disclosure. We take agent containment and kernel isolation issues very seriously and will work with you to verify and patch the vulnerability promptly.
